## 一、总体设计

### 1.1 目标结构

```
设置面板
├─ 远程与存储（原「远程存储」改名，tab id 仍为 remote-storage）
│   ├─ 顶栏 tab A：远程存储   ← 存储类源 profile 管理（协议扩展 + 双路径 + 浏览/搜索）
│   └─ 顶栏 tab B：开放门户   ← 开放数据门户目录 + 凭据管理 + 测试
└─ 数据源（tab id 仍为 data-source）
    ├─ 顶栏 tab A：本地数据源 ← 细分路径配置 + 「可用数据集」注册表
    └─ 顶栏 tab B：远程数据源 ← 动态分组（按远程与存储中的源）+ 浏览/搜索/添加为可访问数据源
```

### 1.2 已确认决策（用户拍板）

| 决策点 | 结论 |
|---|---|
| 凭据查看权限 | **脱敏查看 + 替换**：管理员可看 username/host/port 等非敏感字段；secret 仅显示「已配置」；留空提交=保留、填新值=替换（沿用 GEE/API Key 模式，明文永不出后端） |
| SSH / NFS 深度 | SSH=命令通道+SFTP（复用 paramiko / SshSyncModule）；NFS=**挂载点路径访问**（不引入 Python NFS 协议栈）；局域网共享=UNC 路径/挂载点直连（Windows UNC `\\host\share` 直访，需异构凭据时提示系统级挂载） |
| 门户下载引擎 | 本期**统一 HTTP 预设+凭据模式**（http_open_data 扩展），架构预留 provider 接口；earthaccess/cdsapi 等专用库后续逐门户接入 |
| 传输安全 | 沿用现有体系：写操作 admin-only + 会话 Cookie（HttpOnly）承载新密文 + `/config` 写限流 120/min/IP + 同机构/loopback 部署边界；不新增明文回显端点 |

### 1.3 协议矩阵（远程存储扩展后）

| 协议 | 传输实现 | 凭据 | 双路径回退 | 浏览 | 搜索 |
|---|---|---|---|---|---|
| sftp | paramiko SFTP（现有） | 密码/私钥 | ✅ alt host/port | ✅ | ✅ 受限 glob |
| ssh | paramiko 命令通道 + SFTP 传输 | 密码/私钥 | ✅ | ✅ | ✅ |
| smb | smbclient（现有） | 域账号/密码 | ✅ | ✅ | ✅ |
| ftp / ftps | ftplib（现有） | 账号/密码 | ✅ | ✅ | ✅ |
| gs (gcs) | google-cloud-storage SA JSON（现有） | SA JSON | ✅ alt bucket/endpoint | ✅ | ✅ 前缀列举 |
| http / https | HttpSource（现有，出站 SSRF 校验） | basic/bearer | ✅ alt url | ✅ HTML 目录/仅 test | 按门户 |
| filebrowser | FileBrowser REST（login → JWT → resources/raw/search） | 账号/密码 | ✅ 内网 url ↔ 隧道 url | ✅ | ✅ 原生 /api/search |
| lan（局域网共享） | UNC / 挂载点 Path 直访 | 系统凭据（可选提示挂载） | ✅ alt UNC/挂载路径 | ✅ | ✅ 受限 glob |
| nfs（挂载点） | 挂载后按本地路径访问 | 系统级挂载提示 | ✅ alt 挂载点 | ✅ | ✅ 受限 glob |

双路径语义：每 profile 配主访问路径（默认内网 host/url）+ 备用访问路径（隧道 url/IP）；`auto` 模式下主路径连接异常（连接超时/认证失败以外的网络错误均试备）自动切备用并记录 failover 状态；`manual` 模式仅手动切换；`off` 禁用备用。

## 六、风险与对策

| 风险 | 对策 |
|---|---|
| 双路径回退误判（慢认证失败反复切换） | 仅网络类异常回退；认证错误不回退；failover_state 落库，UI 可见；手动 reset |

| 门户目录与 open_data_presets 双真源漂移 | labels 由目录生成；presets 仅为 URL 覆盖；check 脚本后续可加 portal catalog 断言 |
| dataset registry 与 DATASET_REGISTRY 静态漂移 | 启动同步 + `source=algorithm_registry` 只读保护；path 覆盖存 registry，不改算法包 |
| `test_workflow_routes.py` SQLite WAL 磁盘 I/O 环境失败 | 已知环境限制（非代码问题），该文件验证移至 CI/本地非沙箱环境 |
| OpenAPI 漂移 | 每次契约变更后立即 `npm run gen:types` + 重导 openapi.json，E/F 阶段集中 check |
| 旧 `hpc/win11/nas` 链路兼容 | `/api/remote/*` 路由本期**不删**（SshSyncForm 兼容模式仍可用）；下线另立计划 |
