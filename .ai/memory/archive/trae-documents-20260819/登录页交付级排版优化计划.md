# 登录页交付级排版优化计划

## 概述

聚焦 `Code/frontend/src/views/LoginView.vue`（唯一功能改动文件），将品牌区重构为居中锁版：**英文缩写 SGFS 置于图标正下方**、**中文名与英文名同行显示**、**删除"登录以访问地图分析…"等提示文案**、**密码框增加显示/隐藏眼睛按钮**，并同步微调间距节奏与响应式降级，使登录卡达到交付水平。新增一个 LoginView 组件回归测试；不改 `BRAND` 常量、`TextField.vue`、`ModeToolbar.vue` 与背景动效。

## 现状分析（Phase 1 探索结论）

- **品牌区现状**（`LoginView.vue` L185–197）：图标左置（`BrandMark :size="56"` + 脉冲外环），右侧文案列为 `eyebrow(SGFS)` → `h1(星地融合土壤数据平台)` → `subtitle-en(Star-Ground Fusion Soil Data Platform)` → `subtitle(登录以访问地图分析、工作流与数据服务)`；卡片底部另有 `footer-note(会话通过安全 Cookie 维持…)`。
- **品牌常量**（`src/ui-copy/brand.ts`）：`abbr='SGFS'`、`shortName='星地融合土壤数据平台'`（10 汉字）、`displayNameEn='Star-Ground Fusion Soil Data Platform'`（37 字符）。`BRAND.eyebrow` 同时被 `ModeToolbar.vue`（应用内工具栏）引用——**本次不动工具栏**。
- **密码框现状**：裸 `<input type="password">`，无可见性切换；全仓库无既有 showPassword 模式（`ApiKeySettings` 等处同样裸 password 输入）。
- **设计系统**：`src/styles/tokens.css` 单一真源（深空蓝青主题、Sora + IBM Plex Mono、`--space-*`/`--radius-*`/`--motion-*` 令牌）；`lucide-vue-next@0.577.0` 已是依赖且 `ModeToolbar` 以 `<Move :size="14" />` 方式使用。
- **测试惯例**：无既有 LoginView 渲染测试；组件测试经 `@/test-utils`（导出 `mount`/`createPinia`/`createRouter`/`createMemoryHistory`，解决 root 外解析问题），参照 `Test/frontend/components/service-connectivity-banner.test.ts`（`// @vitest-environment jsdom` 头）。auth store 创建无副作用（`bootstrap` 为显式函数）；`auth-router.test.ts` 证明 router 单例可直接导入。
- **尺寸预算**（root=15px）：卡片 `min(28rem,100%)`=420px，左右内边距 `--space-6`×2=48px → 内容宽 **372px**。若维持图标左置，右侧仅约 300px，无法容纳"10 汉字 + 37 英文字符"一行 → **必须居中堆叠锁版**。

## 改动方案

### 1. `Code/frontend/src/views/LoginView.vue` — Script

```ts
import { Eye, EyeOff } from 'lucide-vue-next'
// 新增状态
const showPassword = ref(false)
```

其余逻辑（`submit`/`retryBootstrap`/`devHint` 预填）不变。

### 2. Template — 品牌区重构为居中锁版

```html
<div class="brand-block">
  <div class="brand-mark" aria-hidden="true">
    <BrandMark :size="56" />
    <span class="mark-ring-outer"></span>
  </div>
  <p class="brand-abbr">{{ BRAND.abbr }}</p>
  <div class="brand-names">
    <h1>{{ BRAND.shortName }}</h1>
    <span class="brand-name-sep" aria-hidden="true"></span>
    <span class="brand-name-en">{{ BRAND.displayNameEn }}</span>
  </div>
</div>
<div class="brand-divider" aria-hidden="true"></div>
```

**删除**：`eyebrow` 段、`subtitle-en` 段、`subtitle`（提示语）段、`footer-note` 段。
**保留**：`banner-warn`（bootstrap 断联 + 重试按钮）、`dev-hint`（仅 DEV 构建出现，功能性）、`banner-error`、`AppButton block primary`（进入系统）。

目标视觉（桌面）：

```
        [BrandMark 56px + 脉冲外环]
              S G F S                ← abbr，mono 宽字距，accent 色
 星地融合土壤数据平台 │ Star-Ground Fusion Soil Data Platform   ← 一行，居中
 ────────────（渐隐分隔线）────────────
 用户名  [____________________]
 密码    [____________________] 👁
 [           进入系统            ]
```

### 3. Template — 密码框眼睛按钮

```html
<label class="field">
  <span class="field-label">密码</span>
  <div class="input-wrap">
    <input
      v-model="password"
      :type="showPassword ? 'text' : 'password'"
      autocomplete="current-password"
      placeholder="请输入密码"
      required
    />
    <button
      type="button"
      class="password-toggle"
      :class="{ 'is-visible': showPassword }"
      :aria-label="showPassword ? '隐藏密码' : '显示密码'"
      :aria-pressed="showPassword"
      @mousedown.prevent
      @click="showPassword = !showPassword"
    >
      <EyeOff v-if="showPassword" :size="15" />
      <Eye v-else :size="15" />
    </button>
  </div>
</label>
```

要点：`@mousedown.prevent` 防止按钮抢焦点，保持输入框聚焦发光态；图标语义为"密文态显示 Eye（点击可看）、明文态显示 EyeOff（点击隐藏）"；label 内嵌 button 合法且点击不会被 label 转发（交互元素吞掉点击）。

### 4. Style（scoped CSS）

**新增/替换：**

- `.brand-block`：`flex-direction: column; align-items: center; text-align: center; margin-bottom: 0`（间距交给分隔线）。
- `.brand-abbr`：`font-family: var(--font-mono); font-size: 0.78rem; letter-spacing: 0.42em; margin: var(--space-3) 0 0; margin-right: -0.42em`（光学居中补偿）；`color: var(--accent); font-weight: var(--font-weight-semibold)`；保留 eyebrow 原有 `text-shadow` 微光。
- `.brand-names`：`display: flex; align-items: baseline; justify-content: center; flex-wrap: wrap; column-gap: 0.55rem; row-gap: var(--space-1); margin-top: var(--space-3)`。
- `.brand-names h1`：`margin: 0; font-size: 0.95rem; font-weight: var(--font-weight-semibold)`；保留原渐变文字（`background-clip: text`）。
- `.brand-name-sep`：`align-self: center; width: 1px; height: 0.85em; background: var(--border-strong)`。
- `.brand-name-en`：`font-size: 0.68rem; color: var(--text-muted); letter-spacing: 0.02em; white-space: nowrap`（Sora 正文族，**不用 mono**——等宽字体更宽会破坏一行预算）。
- `.brand-divider`：`height: 1px; margin: var(--space-5) 0; background: linear-gradient(90deg, transparent, var(--border-default), transparent)`。
- `.input-wrap`：`position: relative`；`.input-wrap input { padding-right: 2.8rem }`（其余样式由既有 `.field input` 级联继续生效）。
- `.password-toggle`：绝对定位 `right: 0.55rem; top: 50%; translateY(-50%)`，26×26px，`border: none; background: transparent; color: var(--text-muted); border-radius: var(--radius-sm)`；hover → `color: var(--accent); background: var(--accent-surface)`；`focus-visible` → `outline: 2px solid var(--accent); outline-offset: 2px`；`.is-visible` → `color: var(--accent)`。
- `.login-card` 内边距对称化：`var(--space-7) var(--space-6)`（移除 footer 后上下 36px 对称）。
- `prefers-reduced-motion` 块补充 `.password-toggle { transition: none }`。

**删除规则**：`.brand-copy .eyebrow`、`.brand-copy h1`、`.subtitle-en`、`.subtitle`、`.footer-note`，及旧 `.brand-block` 横向布局。

**一行预算校验**：中文名 0.95rem×10 ≈143px + 分隔线 ≈17px + 英文名 0.68rem×37 ≈190px ≈ **350px < 372px**（余量 ~20px）。实现后须截图目检；若 Sora 实测偏宽，优先微调英文名至 0.65rem 或中文名至 0.92rem，保持一行不溢出。窄屏（<420px）依赖 `flex-wrap` 降级为两行居中。

### 5. 新增测试 `Test/frontend/views/login-view.test.ts`

参照 `service-connectivity-banner.test.ts` 惯例（`// @vitest-environment jsdom`，`@/test-utils` 垫片）。挂载方式：

```ts
import { mount, createPinia, createRouter, createMemoryHistory } from '@/test-utils'
import { setActivePinia } from 'pinia' // 垫片已导出，直接从垫片取亦可
```

用例：

1. **品牌锁版**：`.brand-abbr` 文本为 `SGFS` 且位于 `.brand-mark` 之后（DOM 顺序断言）；`.brand-names` 内同时含 `星地融合土壤数据平台` 与 `Star-Ground Fusion Soil Data Platform`。
2. **提示语已移除**：渲染文本不含 `登录以访问地图`、不含 `会话通过安全 Cookie`。
3. **眼睛按钮切换**：初始 `input[type=password]`、`aria-pressed="false"`；点击 `.password-toggle` 后 `type=text`、`aria-pressed="true"`、`aria-label="隐藏密码"`；再点击恢复 `password`。

auth store 真实创建（无副作用），无需 mock；`devHint` 在测试环境 `import.meta.env.DEV=false` 下为 null。

## 假设与决策

| # | 决策 | 理由 |
|---|------|------|
| 1 | 居中堆叠锁版（图标上、SGFS 下、名称行居中） | 图标左置时右侧仅 ~300px，放不下"10 汉字+37 英文字符"一行；居中锁版是交付级登录页主流范式，且给名称行完整 372px 宽度 |
| 2 | `footer-note`（Cookie 安全提示）一并删除 | 属"等内容"提示性文案；交付级登录卡以最小说话量为优 |
| 3 | 眼睛按钮用 `lucide-vue-next` 的 `Eye`/`EyeOff` | 仓库既有依赖与 `ModeToolbar` 使用惯例，不自绘 SVG |
| 4 | 保留背景动效（地球/星点/扫描线/光晕）与卡片入场动画 | 已具品牌辨识度，本次聚焦排版而非重设计 |
| 5 | 不迁移到 `TextField.vue`、不给其加通用 toggle prop | 登录页输入框有专属玻璃质感样式；本地实现改动面最小，不影响其余 7 处 password 输入 |
| 6 | `BRAND.eyebrow` 字段与工具栏不动 | 工具栏是另一锁版场景；仅登录页改用 `BRAND.abbr` |
| 7 | `dev-hint` 保留 | 仅 DEV 构建出现的功能性提示，生产不可见 |
