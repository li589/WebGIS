## 三、假设与决策

1. 不修项及理由：算法包反向 import 后端（需桥接协议改造）；`data_access/sources/http.py` 缓存语义独立（收敛风险大于收益）；`source_fetcher` 续传上移 shared（两部署面 requirements 牵动，后续项）。
2. NSMC 多账号轮换在算法 worker 进程内实现（顺序尝试+冷却），不做跨进程账号池服务。
3. avg 产品复用 `omega_sf_*_block_dir` 类型优先，命名不兼容才加新映射。
4. 在线线直连「下载→转换→反演→图层」，D1→D2 落盘桥接只做 `omega_block_smap_single` output_dir 补齐。
5. UI 修复以浏览器实测为准，静态风险点是候选不是任务。
6. 凭据：earthdata 复用现有加密库条目；NSMC 3 账号执行时经 API 注入；明文不入任何文件/提交/日志。
7. 外网/数据源不可用时：反演在线真跑降级为本地缓存数据验证链路，并在进度文档记录原因。
