## 一、现状分析（Phase 1 探索结论）

三条并行探索已完成全部数值链路取证，关键结论均已由本会话对照源码逐行核实：

### 整体评价
数值工程质量**高于典型科研代码**：全程 float64 零 float32 截断、`math.expm1` 抗相消手法贯穿全部正向算子（omega.py:471/525/618/709、omega_sf.py:1113、inversion.py:128）、"哨兵阈值 + np.errstate + NaN 出口闸门"三件套模式统一、golden 回归 fixture 以 rtol=1e-9/atol=1e-11 锁死 8 种组合、全部随机源固定 seed。

### 核实后决定「不改」的项（报告记录 + 就地注释）

- `omega.py:2110-2114` `minimize_scalar xatol=1e-4`——OMEGA 收敛容差是有意设计的产品精度让步，仅文档记录。

- `timeseries_analysis.py:108` Kendall tau 分母未修 ties——统计口径问题非浮点缺陷，报告记录。
- float32 落盘策略（`_raster_ops.py:342`、`gis_ops.py:371`、`raster_writer.py:201`）——文件头已声明"float64 计算、float32 落盘"为设计决策，量化 ~1e-7 相对误差可接受。

## 二、变更方案

### 批次 P0：运行时探针（先证伪/证实 C2，再动代码）
新建 `Test/algorithms/test_universal_reader_netcdf_scaling.py`：
- 用 netCDF4 写 int16 变量 + `scale_factor=0.01` + `add_offset=273.15` + `_FillValue=-32768` 的 fixture 文件，经 universal_reader 的 NetCDF 路径读取；
- 断言：物理值 == raw×0.01+273.15（**恰好一次缩放**）、fill→NaN、无掩码泄漏。当前代码应失败（红），修复后绿——即 TDD 载体，同时永久锁死该行为。

### 批次 P1：Critical 修复（每项先写失败测试再修）

**P1-1 `algorithms/inversion.py` + `algorithms/omega.py`（C1+W3）**
- inversion.py:372-381：仿 omega.py:1227-1247 模式——入口处 porosity 无效（≤0.02 或非有限）直接返回 `(nan, nan)`；`x0` 双分量 clamp 进 bounds（`x0[0]=min(max(0.2, 0.02), porosity)`，tau 分量同理 clamp 进 (0,5)）。
- `ddca_retrieve_grid`(:503-513) valid_mask 增加 porosity 有限性与下界检查（与 `retrieve_dynamic_h_grid`:308-311 对称）。
- omega.py:2502-2507：h0/alpha0 clamp 进 `halpha_lower_bounds/halpha_upper_bounds`。
- 新测试 `Test/algorithms/test_inversion_x0_bounds.py`：porosity=0.1（<0.2）单像元不抛异常返回有限值或 NaN；含单坏像元的 grid 批处理整批不崩、坏像元为 NaN。

**P1-2 `data_access/universal_reader.py`（C2）**
- 在 `values = var[tuple(slices)]`(:343) 之前，对 netCDF4 变量调用 `var.set_auto_maskandscale(False)`（读原始整数，手工清洗/缩放管线成为唯一真源，与既有代码意图一致）；读取后若仍返回 MaskedArray 则 `values = np.asarray(values.filled(fill_value), dtype=np.float64)` 防御性兜底。
- 修 :373 恒 False 的死条件（astype 后已 float64，仅保留 `var.dtype == np.int16` 判定）。
- 验收 = P0 探针测试转绿。

**P1-3 `data_access/spatial_aligner.py`（C3）**
- :321-322 的 `np.linspace(north, south, target_height)` / `linspace(west, east, target_width)` 替换为 `pixel_center_axis(north, south, target_height)` / `pixel_center_axis(west, east, target_width)`，与 :193-199 返回坐标同一函数、同一语义。
- 新测试 `Test/algorithms/test_spatial_aligner_grid_consistency.py`：一维规则网格源上，目标格网中心处的插值值应等于源同位置值（无半像素偏移）；且插值所用轴 == 返回坐标轴。

**P1-4 `ingest/gldas_nc4_to_mat.py`（C4）**
- `_interp_gldas_field`：field 含非有限点时，改用与 spatial_aligner:334-350 相同策略——`griddata((lon_valid, lat_valid), values_valid, (lon_tgt, lat_tgt), method="linear", fill_value=nan)`（NaN 点不进输入，无涂抹）；全有限时保留 RegularGridInterpolator（快路径）。
- 增加 lat/lon 单调性校验：非升序时先翻转（`[::-1]`）再插值，乱序 raise ValueError。
- 在 `Test/algorithms/test_gldas_nc4_to_mat.py` 增补用例：field 中心一个 NaN → 其邻域目标格点不得变 NaN（凸包内有效）。

### 批次 P2：Warning 修复

**P2-1 JSON NaN（W1）**：statistics.py / stats_histogram.py 各加 `_json_safe()`（递归将非有限 float → None），两处 `json.dumps` 前过一遍并加 `allow_nan=False` 硬门。测试：全 NaN 栅格 stats → `json.loads` 可解析且含 null。

**P2-2 `modules/fitting.py`（W2）**：polyfit 校验 `1 ≤ degree ≤ 6` 否则 ValueError，`np.RankWarning` 捕获转显式日志；exp 拟合 `a0 = float(np.nanmax(values))`（数据量纲感知）+ b0=0.01 保留；`fitted` 落盘前 `fitted[~np.isfinite(fitted)] = np.nan`。测试：增长型数据拟合 → MAT 路径无 inf。

**P2-3 `modules/_raster_ops.py`（W4）**：分块统计改为逐块 (count, mean, M2) 累计 + Chan 并行合并公式，`var = M2_total/count`（保持 ddof=0 口径与 `max(·,0)` 守卫）。测试：mean=300、σ=1、N=1e6 随机数据 vs `np.std` 断言 rtol 1e-12（旧公式在该场景误差 ~1e-4，新测试同时锁精度）。

**P2-4 `ingest/fy_preprocess.py`（W5）**：变量创建期以 `createVariable(..., fill_value=np.nan)` 设置标准 `_FillValue`（float NaN 合法），数据体维持 NaN——标准掩膜消费端得到 mask、原始读取端得到 NaN，两种语义自洽；删除写后 `var.FillValue=` 的非标准属性赋值。执行时先 grep 这些 .nc 产物的消费端确认无人依赖旧属性名（`FillValue`）。
