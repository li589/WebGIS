# 工作流图层组织、多边形绘制与提示框优化计划（2026-08-17）

## Summary

以 brooks-sweep 范围化模式（只扫三个任务相关模块，非全仓库四维清扫；Safe/Extended-Safe 修复直接应用，Residual 记录不应用）修复三个前端为主的 UI 缺陷：

1. **工作流运行后图层组织**（用户确认 **C 档**）：成功 run 清理空占位成员 + 恢复链按 manifest 生成成员 + 物化图层优先归入目标组 + 后端 `imported-*` 图层 ID 按 workflow 去重（重复运行覆盖同一图层）。

3. **提示框统一**：保持中上位置（统一 110px 基准线，避开 24.8~90px 顶栏带）、实底背景（`--surface-1/2`）、z-index 语义化，不重排 z 体系。

## Assumptions & Decisions

1. **范围化 sweep**：本轮只扫/修三个任务相关模块及其直接消费者，不跑全仓库四维清扫；每项修复按 Safe（单文件局部）/ Extended-Safe（多文件但测试护住）/ Residual（公共接口破坏或无测试）分类，前两类直接应用并跑测试验证，Residual 记录待审。**不自动 commit/push**（sweep 惯例；提交另行按仓库硬约定）。
2. 任务1 取 **C 档**（用户确认）：含后端 ID 去重；执行时先盘点 `stable_imported_layer_id` 全部调用点再定哈希成分，保证旧 `imported-*` 仍可懒加载。
3. 任务2 导出**仅修提示文案**（用户确认），不新增草稿直导入口；已保存图层导出链路不动。
4. 任务3 **保持中上位置**，统一 110px 基准；实底 `--surface-1` 背景 + 语义色文字；z 体系不重排（`--z-toast:100` 与实际的脱节记录为 Residual，不在本轮改）。
5. 未定义 CSS 变量三处组件**直接替换**为已定义 token，不在 tokens.css 加别名。
6. UI 文案中文（沿用 `src/ui-copy/` 模式）；Celery/接口元数据不动。
7. 旧 run 快照恢复兼容：无 manifest 的历史 run 回退 SM/VOD/OMEGA 占位（现状行为）。
