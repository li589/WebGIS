# CGDA 文档中心

综合地理数据分析系统（CGDA）公开文档仓库，按主题分类存放架构设计、规范协议、专题研究、代码审查、结题材料等。

> 文档维护原则：活文档以各模块 README 为准；带日期的快照文档仅作历史参考。

## 目录结构

| 编号 | 目录 | 说明 |
|------|------|------|
| 01 | `01-协作规范/` | 项目任务清单、工程收口仪表盘、协作流程约定 |
| 02 | `02-架构设计/` | 后端架构、空间表设计、工作流编辑器、架构图 |
| 03 | `03-规范协议/` | 技术栈规范、PRD、命名规范、工作流节点约定、数据源说明 |
| 04 | `04-执行部署/` | 本地联调环境说明、交付清单 |
| 05 | `05-专题研究/` | 天气渲染、omega_sf 反演、数据集目录、命名研究等专项 |
| 06 | `06-代码审查/` | 各轮代码审查报告与问题追踪 |
| 07 | `07-工程保障/` | 预启动检查、工程收口、功能验证、修复计划 |
| 08 | `08-HTML报告/` | 可交互 HTML 报告（project-overview、frontend-design-audit），支持在线更新 |
| 09 | `09-结题材料/` | 结题报告、验收材料、修改意见 |
| 10 | `10-参考示例/` | Windy 参考等外部参考资料 |
| 99 | `99-历史归档/` | 代码事实同步快照、历史任务记录等归档材料 |

## HTML 报告（可更新）

以下 HTML 报告为可交互、可持续更新的活文档：

- **`08-HTML报告/project-overview/`** — 项目全景总览（架构、技术栈、模块、数据流）
- **`08-HTML报告/frontend-design-audit/`** — 前端设计审查报告

## AI 工作区（`.ai/`，本地专用）

AI 提示、技能、计划、进度、记忆等本地工作内容位于仓库根 `.ai/` 目录，**不上传 GitHub**。其中审查报告等需公开的内容已复制到本仓库对应分类。

- `.ai/rules/` — 约定单一真源（项目约定、Git 提交规范、决策策略）
- `.ai/skills/` — 可复用技能（工作流设计、反演、数据接入等）
- `.ai/plans/` — 实施计划
- `.ai/progress/` — 进度与验证追踪
- `.ai/memory/` — AI 记忆与历史上下文
