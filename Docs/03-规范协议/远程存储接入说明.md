# 远程存储接入说明

最后更新：2026-08-20

## 能力概览

算法取数（`data_access`）与下载链（`source_fetcher`）共用 [`Code/shared/remote_sources/`](../Code/shared/remote_sources/)：

| Scheme | Transport | 备注 |
|--------|-----------|------|
| `sftp://` | paramiko | SSH 仅 SFTP，无远程命令 |
| `smb://` | smbprotocol | `smb://host/share/path` |
| `ftp://` / `ftps://` | ftplib | 明文 FTP 默认关闭 |
| `gs://` | google-cloud-storage | 服务账号 JSON 存入凭证 secret |

工作流下载节点另有两条运行时路径（凭据仍只在服务端解密，不入作业负载）：

| 节点 | 用法 |
|------|------|
| `download/ssh_sync` | `server_type` 为 `hpc`/`win11`/`nas` 时走遗留内置；其它值视为「远程与存储」profile id（协议 `ssh`/`sftp`/`filebrowser`）。尊重 `failover_state.active=alt` 双路径；表单字段 `start_date`/`end_date`、`file_filter` 会传给同步逻辑（兼容历史 `date_start`/`date_end`） |
| `download/http_open_data` 及 FY/NSIDC/GLDAS 下载 | 开放门户预设与凭据见设置 → **远程与存储 → 开放门户**；节点账号留空时回退门户凭据库。FY 在线（`fy_download` NSMC 路径）走 NSMC 新门户（DataPortal API，RSA+验证码登录）：凭据用门户 `cma_nsmc` accounts（用户名+密码）；会话缓存复用 `CGDA_NSMC_SESSION_FILE` 或 `<BACKEND_DATA_ROOT>/_runtime/cache/nsmc_session.json`；无 `ddddocr` 时需人工预热（`Tools/nsmc_online_probe.py prepare → login --code <验证码> → export`）；限额保护默认每日 2 文件/账号（节点参数 `max_files_per_day` / `download_interval` 可调，频控自动 600s 冷却切换账号） |
| `download/cds_download` | ECMWF CDS 再分析（ERA5/ORAS5 等）：主路径 `cdsapi` 排队轮询，回退 legacy 静态直链（Range 续传）。凭据经门户 `ecmwf_cds` 或 `BACKEND_CDS_API_KEY` 下发 |
| `download/nomads_grib_download` | NOAA NOMADS GRIB2：主路径 `herbie`（model/product/cycle 参数化物化子集），回退 `filter_*.pl` / 全量文件直连（共享 Range 续传） |
| `download/cdse_download` | Copernicus CDSE 产品：主路径 OData（`cdsapi` 兼容栈 + JSON token），回退 legacy 直链下载 |

### 专用库主 / 回退矩阵

所有新下载节点 `use="auto"`（默认）：专用库未安装或不可用时按矩阵回退，行为对齐 `ingest/nsidc_download.py` 先例：

| 家族 | 主路径 | 回退路径 | 回退语义 |
|------|--------|----------|----------|
| CDS | `cdsapi` | legacy 静态直链 + Range 续传 | 协议无法纯 HTTP 完整复现时**报可诊断错误**（不静默降级） |
| NOMADS | `herbie` | `filter_*.pl` / 全量 GRIB2 直连 | **静默回退**并记 warning |
| CDSE | OData 流式 | legacy 直链 | 同 CDS：不可复现时报可诊断错误 |
| NASA 家族（`http_open_data`） | `earthaccess` | CMR 搜索 + requests | **静默回退**并记 warning |

依赖（`Code/backend/requirements.txt` 与算法包 `requirements.txt` 均已固化版本）：`cdsapi`、`herbie`（试装失败可降级为可选）、`earthaccess`、`cfgrib` + `xarray`（GRIB 读取）。

**GRIB 消费链**：`download/nomads_grib_download` 产出的 `.grib2` 可直接上传进入科学栅格链路（`POST /import/raster/inspect` 枚举变量 → `raster/commit` 抽取为 GeoTIFF，bounds 取自 cfgrib 经纬坐标）；算法侧 `variable_extract` / `format_convert` 节点同样支持 GRIB 输入。离线回归 fixture：`Test/algorithms/fixtures/grib2_t2m_2x2.grib2`（生成器 `generate_grib2_fixture.py` 入库可复现）。

## 配置

1. 设置页 → **远程与存储**（远程存储 profile + 开放门户），或 `PUT /config/remote-storage/{profile_id}`（需写鉴权）
2. URI 绑定凭证：`sftp://nas/data/a.tif?cred=nas-lab`
3. 也可按 host+protocol 匹配默认 profile（启用态、最近更新优先）
4. SMB profile 必须配置 `extra.default_share`，否则连通性测试无法构造 probe URI
5. SFTP 内网可设 `extra.host_key_policy=auto_add`（设置页勾选）
6. 工作流侧浏览/测连：`GET /api/remote/servers`、`GET /api/remote/test?server=`（legacy 名或 profile id）

凭证库：`workflow_state/remote_storage_credentials.sqlite3`，加密 key 与 GEE 相同（`BACKEND_GEE_CREDENTIALS_ENCRYPTION_KEY`）。

### 多机 / Worker

- 凭证 **不**随任务载荷下发；Worker 进程需能打开同一凭证库路径并使用同一加密 key
- 推荐：把 `BACKEND_GEE_CREDENTIALS_DB_PATH` 的父目录放到共享盘，或在每台 Worker 上重建相同 profile 后 `POST .../test` 验证
- API 与 Worker 都要能路由到 NAS（防火墙 / VLAN）

## 图层 / 下载用法

- `default_data_access_sources` 候选可直接写完整远端 URI
- 运维覆盖（推荐，不改坏本地已跑通路径）：环境变量 `BACKEND_REMOTE_LAYER_DATA_URIS`（JSON），或设置页 `PUT /config/data-source/remote-layer-uris`
- 入库校验：URI scheme 须为平台支持的取数协议（`http(s)` / `smb` / `sftp` / `file` / `minio` / `s3` / `demo` 等）；`javascript:` 等危险协议会被拒绝（见 `validate_data_source_uri_for_storage`）

```json
{
  "smap-soil": {
    "SMAP_SPL3SMP_E": [
      "smb://192.168.1.10/Geograph/SMAP/SMAP_L3_SM_P_20220101.h5?cred=nas-lab"
    ]
  }
}
```

注入后远端 URI 排在候选最前；本地逻辑名 / 相对路径仍保留作回退。

- 就绪检查：URI 合法 + 凭证可解析；可选 `BACKEND_REMOTE_READINESS_PROBE=true` 做短超时连通性 probe（**不**因对象缺失而 blocked）
- **materialize 落盘后**才在资源 metadata 标 `materialization_status=ready`（任务执行期）；与图层 `run_readiness` 不是同一概念
- 单文件下载上限：`BACKEND_REMOTE_MAX_BYTES`（默认 512 MiB）；大产品务必调高

## 设置页测试

## 密钥历史与本机偏好（2026-07-17）

- **服务端历史**：底图 / `backend_auth` 在 `api_keys.sqlite3` 的 `api_key_history` 表中加密归档；远程存储密码/私钥在 `remote_storage_secret_history`。每次轮换若明文变化则归档，默认每条目保留 20 条（`BACKEND_API_KEY_HISTORY_LIMIT` / `BACKEND_REMOTE_STORAGE_HISTORY_LIMIT`）。
- **API**：`GET|DELETE /config/api-keys/{name}/history`、`POST .../history/{id}/restore`；远程存储同路径前缀 `/config/remote-storage/{id}/history*`。需写鉴权。
- **本机偏好**：浏览器 `localStorage` 保存写请求密钥（`cgda.backend_write_api_key`）、历史折叠/备注、设置默认 Tab。设置页可「清除本机偏好」；**不会**删除服务端历史。
- **GEE**：服务账户 JSON 体积大，不默认多副本存历史；轮换请重新粘贴 JSON（指纹/元数据级审计可后续扩展）。

详见设置页「API管理 / 远程存储」提示文案。
