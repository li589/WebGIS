## 启动与基础设施

- **本地 Python 运行时（硬约定）**：`Env/Python312`（Windows: `Env\Python312\python.exe`）。勿用系统 PATH 中的其它 Python。
- **Windows / Docker（硬约定）**：Docker Desktop 与启动终端须以**管理员身份**运行，否则可能镜像无法访问、volume/配置读失败或部分容器起不全。
- 一键联调：`start.bat` / `stop.bat`（Windows）或 `./start.sh` / `./stop.sh`（强制上述解释器）；亦可 `Env\Python312\python.exe launch.py …`
  - `start` / `restart` — 运行栈 + FastAPI + Celery + **Nginx Gateway**（静态 `frontend/dist` + 反代 API）
  - `start --vite` — 同上，前台改 Vite HMR（会停 Gateway；同端口互斥）
  - `start gateway` — 仅 Nginx 同域入口 `:5175`（`--rebuild-frontend` 可强制 rebuild dist）
  - `sync` — 数据面同步（默认 `open-meteo-sync`）
  - `stop` / `stop gateway` / `status` / `flush`
- 运行栈：`Code/backend/docker-compose.yml`（Redis `:6379`，MinIO `:9100/:9101`，Open-Meteo API `:8080`）
- 数据栈：`Code/infra/data-sync/`（named volume，不进项目目录）
- 网关栈：`Code/infra/gateway/`（compose project `gateway`，容器 `cgda-gateway-nginx`）
- 前端 Node 可另用本机 Node；**后端/Worker/pytest 必须走 Env/Python312**
- 默认入口：Nginx Gateway `http://localhost:5175` + API `http://127.0.0.1:8000`；详见 `Code/infra/gateway/README.md`
