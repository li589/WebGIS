## deck.gl 评估结论（2026-08-30）

**结论：暂不引入。** 本表此前标注为「规划中」，易被误读为"待办项、迟早要上"，故在此固化评估结论。

### 现状事实

| 检查项 | 结果 |
|---|---|
| `Code/frontend/package.json` | **无 deck.gl 依赖** |
| `Code/frontend/src`、`Code/weixin` | **源码零引用** |
| 对照：Cesium | `cesium` 已接入实验双引擎（设置可选）；`vue-cesium` 依赖仍在 package 但主路径为自研 `globe-engine/` |

即 deck.gl 与 Cesium 状态不同：后者已可在实验设置下挂载，前者是「连依赖都未装」。

### 排期决策

`.ai/plans/2026-08-12-p2-backlog-plan.md` 已明确：PostGIS / Cesium 主链 / **deck.gl** / TiTiler / Martin / 全站容器化 / SSE — **不排进当前 sprint**。
`.ai/progress/2026-08-04-pending-tasks-audit.md` 将其归入「未开始（C）— 平台 backlog（非本期）」。

### 未引入的原因：GPU 渲染需求已由自研 WebGL 图层承担

本项目走的是 **MapLibre + 自研 WebGL 图层**路线，而非叠加一层通用渲染框架：

- 风场粒子 → `wind-particle-webgl-shaders.ts`
- 标量场上色 → `scalar-field-webgl-shaders.ts`
- 3D 地球昼夜 → WebGL custom layer（`globe-night-mask-layer.ts`）

deck.gl 原本设想的生态位（2D 模式下百万级散点 / 热力 / 网格的"透明玻璃板"）尚未空出。

### 触发条件（满足其一即重新评估）

1. 出现**真实的百万级散点/热力渲染场景**（如大范围逐栅格土壤水分反演结果直接前端渲染）
2. 现有 MapLibre GeoJSON source 路径在**实测帧率**上扛不住（先试 `maxzoom` 限深等既有手段，见 3D 昼夜优化经验）

重启评估时的**最小验证动作**：用真实数据集做 10 万 / 100 万点的帧率对比，以数据决定是否值得引入——不按"规划中"字样默认推进。

## 启动与基础设施

- **本地 Python 运行时（硬约定）**：`Env/Python312`（Windows: `Env\Python312\python.exe`）。勿用系统 PATH 中的其它 Python。
- **Windows / Docker（硬约定）**：Docker Desktop 与启动终端须以**管理员身份**运行，否则可能镜像无法访问、volume/配置读失败或部分容器起不全。
- 一键联调：`start.bat` / `stop.bat`（Windows）或 `./start.sh` / `./stop.sh`（强制上述解释器）；亦可 `Env\Python312\python.exe launch.py …`
  - `start` / `restart` — 运行栈 + FastAPI + Celery + **Nginx Gateway**（静态 `frontend/dist` + 反代 API）
  - `start --vite` — 同上，前台改 Vite HMR（会停 Gateway；同端口互斥）
  - `start gateway` — 仅 Nginx 同域入口 `:5175`（`--rebuild-frontend` 可强制 rebuild dist）
  - `sync` — 数据面同步（默认 `open-meteo-sync`）
  - `stop` / `stop gateway` / `status` / `flush`
- 运行栈：`Code/backend/docker-compose.yml`（Redis 宿主机 `:16379`→容器 6379，MinIO `:9100/:9101`，Open-Meteo API `:8080`）
- 数据栈：`Code/infra/data-sync/`（named volume，不进项目目录）
- 网关栈：`Code/infra/gateway/`（compose project `gateway`，容器 `cgda-gateway-nginx`）
- 前端 Node 可另用本机 Node；**后端/Worker/pytest 必须走 Env/Python312**
- 默认入口：Nginx Gateway `http://localhost:5175` + API `http://127.0.0.1:8000`；详见 `Code/infra/gateway/README.md`
