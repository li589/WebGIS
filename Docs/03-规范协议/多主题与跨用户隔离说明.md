# 多主题与跨用户隔离说明

> 状态：现行（2026-09）。产品主题（同 SPA）+ 资源 ACL 合并规则；用户**强制**绑定主题；图层分组预设按主题直写。

## 主题模型

- 单一后端 + 单一 SPA；**每个用户必须绑定一个有效 `theme_id`**（不可清除）。
- 默认 / 主入口种子主题：`slug=sgfs`（**星地融合土壤数据平台** / SGFS）。启动时 `ensure_primary_theme` 播种，并把 `theme_id` 为空或指向已删主题的用户回填到 primary。
- 主题承载品牌（中/英名、缩写、描述、logo）与**默认**资源 ACL。
- 用户级 `user_resource_permissions` 为**覆盖**（同资源优先于主题默认）。
- `permission_mode`：用户行有效则用之，否则继承主题 `default_permission_mode`。
- `admin` 绕过 ACL；地图目录读与绑定用户一致——消费**自身绑定主题**的分组预设（无预设则种子基线）。

管理入口：设置 → 账户 → **主题管理**（默认 ACL + 分组预设状态）与用户列表的 **权限覆盖** / **主题**列。

## 图层分组预设（按主题）

| 项 | 说明 |
|----|------|
| 存储 | SQLite `theme_layer_group_presets`（`payload`: `groups` + `assignments` + `display_names`） |
| 编辑 | 管理员在侧栏「分组管理」或主题管理「编辑本主题分组」中，**以目标主题直写**（`?theme_id=`）；首次写入时从种子 materialize |
| 消费 | 绑定该主题且有预设 → 主题快照；无预设 → `catalog_seeds` 种子基线 |
| 清除 | `DELETE /layers/categories/theme-preset/{id}` → 绑定用户回落种子 |
| 显示名 | 预设内 `display_names[layer_id]` 覆盖目录 `display_name`（不改 `layer_id`、不写种子 JSON） |
| 可见性 | `LayerCategoryDef.hidden` 隐藏顶层组；`hidden_sub_categories` 隐藏二级组类名。消费者 `GET /layers/categories`（无 `theme_id`）过滤 `hidden` 顶层组，仍下发 `hidden_sub_categories` 供侧栏 pills/条目过滤；管理员 `?theme_id=` 预览与 theme-preset GET **全量**以便编辑。隐藏不删 `assignments`；被隐藏组下的图层在侧栏不再成组出现 |
| 种子 JSON | **永不**被运行时写操作修改；`gen:catalog` / `check:catalog` 口径不变 |
| 兼容 | 省略 `theme_id` 仍可写个人工作区；`POST …/sync-to-theme/{id}` 可作为一次性导入 |

相关 API（均需 admin 写）：`POST/PATCH/DELETE /layers/categories*`、`PUT …/order`、`PUT …/members`、`GET/PUT/DELETE …/theme-preset/{id}`、`PUT …/theme-preset/{id}/display-names`。

## 本迭代已隔离

| 面 | 机制 |
|----|------|
| 浏览器工作区 / dismissed / 显示名 / tracked runs / 绘图草稿 | `user-local-isolation`：键 `{base}:u{userId}`；登出清敏感 `cgda.*` 与遗留未作用域 `geo:*` |
| 服务端工作区 | `/workspace` 按 `user_id` |
| 工作流运行 / 产物 / 定时器 | 已有 `owner` / `user_id` 过滤 |
| 导入作业列表 | `owner_user_id`；非 admin 仅见本用户 |
| 图层库分组 / 主题显示名 | 按绑定主题的预设（见上） |

## P1 缺口（未在本迭代改 owner）

| 风险 | 说明 | 缓解建议 |
|------|------|----------|
| `imported-*` 叠加层全局池 | 无 owner；`open` 模式下知 id 即可瓦片/导出 | 非 admin 主题用 `whitelist`；后续为导入层加 `owner_user_id` |
| 用户工作流定义共享目录 | `author="user"` 字面量、文件池共享；`open` 可见他人定义 | 主题 whitelist + 后续按用户/主题分目录 |
| `data_source` ACL 类型 | 可配置，热路径尚未 `check_resource_access(..., "data_source")` | 另开任务接线远程下载门禁 |
| Agent LLM 配置 | 部署级单文件，全用户共用 | 保持 admin 专管；若主题需隔离密钥再拆 `theme_id` |
