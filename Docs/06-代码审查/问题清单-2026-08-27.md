## 二、用户权限配置对话框动态化（commit pending）

`UserPermissionsDialog.vue` 的资源 ID 建议列表从硬编码改为"后端目录 + 静态兜底"：
- 打开对话框时并行 fetch `/layers` + `/provider/workflows` + `/algorithm/workflows`
- 后端 `list_layers` 端点对 admin 跳过 ACL 过滤（`_filter_accessible_layer_ids` 中 `_cred.role == "admin"` 返回全量）→ 管理员可配置 standard 用户因黑名单不可见的图层
- 端点响应仅含公共元数据（layer_id / title / workflow name/description），不含敏感字段
- 任一端点失败时 fallback 到原静态 SUGGESTED_* 列表（向后兼容）

**泄漏审查结论：**
- 前端 dialog 仅 admin 可打开（按钮 disabled + `openPermDialog` 内 `if (!auth.isAdmin) return` 双重闸门）
- `/layers` 对 admin 透明（无 ACL 过滤）；非 admin 即使能调（实际上被前端 + 后端 require_admin 阻挡）也只会拿到自己可见的图层
- `/provider/workflows` 与 `/algorithm/workflows` 仅 require 登录用户，不含敏感字段（layer_id 注册表 + workflow 模板 name/description），原本对 standard 用户可见，没有新引入泄漏面

## 六、晨昏线迭代记录（用户实机反馈驱动的三轮回溯）

### 反馈链条
1. "太平洋永远白天" → 根因：MapLibre `setLight` 对 raster 瓦片无效，时间轴只转视口方位角
2. "两条晨昏线" → 根因：CSS time-sheen/time-band（屏幕空间渐变，位置与地理无关）+ 夜半球 fill layer（地理正确但硬边）双系统叠加
3. "阴面看不见、只剩淡红带、错误的没消失" → 根因：**MapLibre fill stencil 去重**（同层重叠多边形只画一次，嵌套渐变方案失效）；setLight 视口方位公式对 vector 层产生方向错误的光照

### 最终方案（commit 60c9f3b）
- **夜半球 = 60 档互不重叠相邻环带**（左右对称，120 features），fill-opacity 数据驱动按 tier 插值（夜心 ×1.0 → 边缘 ×0.04），档宽 1.5° 视觉连续无缝
- **globe 停用 setLight**（昼夜统一由夜半球 + raster-brightness 负责；sky 大气颜色保留）
- time-sheen/time-band 模板 v-if 移除（2D 保留）
- 光影档位语义：off 不画夜半球 / soft ×0.7 / auto 标准
