# 图层分析面板（InfoPanel GIS）

> 决策日期：2026-08-12  
> 状态：第一期已落地（5 工具 + 产物闭环）

## 目标

在 InfoPanel「分析 / 工具」页实现 ArcGIS 式路径：**选中活跃图层 → 选工具与参数 → 提交 → 新图层 / 图表**。不新开独立分析服务，执行仍走 `POST /workflow-runs`（经薄封装 `POST /analysis/runs`）与 Celery business 池。

## 默认决策

| 项 | 选择 |
|----|------|
| 面板位置 | InfoPanel 工具区（`InfoPanelToolsTab.vue`），非独立抽屉 |
| 一期工具 | `gis.buffer` / `gis.zonal_stats` / `gis.clip` / `stats.histogram` / `gis.reclassify` |
| 执行模型 | 系统种子 `analysis_*.json` + `workflow-runs` |
| 同图层同工具 | `parameters.analysis_exclusivity_key`，服务端 **cancel-then-accept** |
| 同图层不同工具 | 前端最多 2 个并行，超出本地排队 |
| 全局 | 仍受 `BACKEND_MAX_ACTIVE_RUNS`；429 时 runner 指数退避重试 |

## 关键链路

1. **目录**：`GET /analysis/tools?layer_id=&has_raster=&is_weather=` ← `catalog_seeds/analysis_tools.json`
2. **提交**：`POST /analysis/runs` → 解析 overlay 本地路径 → 克隆模板注入 path/bbox/参数 → `submission_service.submit_workflow`
3. **产物**：
   - 通用 `type=raster` GeoTIFF → `python_provider_result_builder` 注册 imported overlay（原生 CRS，**不走** ease2）
   - `gis_zonal_statistics` 额外产出 `table_spec` + bar `chart_spec`
   - 直方图沿用 `stats/histogram` + `viz/chart_generate`
4. **前端**：`stores/analysis-runner.ts` 提交后 `registerExternalWorkflowRun`，图表挂在源图层 `jobLayer`；裁剪/重分类经 materialize 上图

## 验证矩阵（联调）

| 场景 | 期望 |
|------|------|
| 选中导入栅格 → 直方图 | Visual/工具区见 chart + table |
| 导入栅格 → 裁剪（视口 bbox） | ActiveLayers 出现新 `imported-gis-*` overlay |
| 导入栅格 → 重分类 | 同上 |
| 选点 → 缓冲区 | 真 `gis/buffer_analysis` run；πr² 仅作提示 |
| 同工具连点两次 | 仅后一次 run 存活（前次 cancelled） |
| 同图层同时开 3 个不同工具 | 第 3 个本地排队提示 |
| 天气瓦片层 | 多数工具灰显；提示先导出/导入静态栅格 |
| omega 回归 | `_MAPPABLE_PRODUCTS` 块级路径不变 |
