## 一、契约结构

每条预设（种子）是一份节点间生产者/消费者契约：

| 契约要素 | 载体 | 说明 |
|---|---|---|
| 语义声明 | `_meta.name/description/category/tags` | `tags` 含 `"pipeline"` 即被 PipelineLauncher 识别为端到端流水线 |
| 图层绑定 | `_meta.linked_layer_id` | 启动时经 layer→workflow 桥接反向定位；校验器强制该图层存在于 catalog |
| 输入契约 | `data/source` 节点 `dataset_key` ← `path` | dataset_key 是模块间语义键（如 `omega_block_output`） |
| 参数契约 | 模块节点 `algorithm_params` | Launcher 高级参数面板直接透传该对象 |
| 输出契约 | `output/map_layer` 节点 + `extra.outputs` | 前者声明发布图层，后者驱动 Launcher 卡片输出徽标 |
| 占位符 | `{DATA_ROOT}` / `{YYYYMMDD}` | 全部种子 `is_template: true`，运行前替换 |

消费端：PipelineLauncher（tag=pipeline 过滤）、WorkflowEditorPanel（画布）、workflow_timer_service（定时器）、layer_workflow_validator（linked_layer_id 存在性校验）、workflow_request_resolver（layer 桥接补齐 time_range）。

## 四、分析预设（analysis，22 条）

- **ui-panel 系（11 条）**：`analysis_clip / buffer / contour / histogram / raster_calc / raster_to_vector / reclassify / slope_aspect / vector_to_raster / watershed / zonal_stats`。功能：InfoPanel 单步 GIS 分析；输入：注入的栅格/矢量路径 + bbox（种子内为 `{DATA_ROOT}/_runtime/smoke_*` 哨兵路径，运行时由面板上下文替换）；输出：对应分析产物。
- **preprocess 系（2 条）**：`clip_reproject`（裁剪→重投影）、`mask_resample`（掩膜→重采样）。
- **fusion 系（2 条）**：`idw_interpolate`（点→栅格 IDW）、`multi_source_merge`（双栅格加权融合）。
- **stats 系（5 条）**：`correlation`、`correlation+report`、`mean+summary+report`、`summary+chart`、`trend+anomaly`。
- **raster 系（2 条）**：`timeseries_curve`（时序曲线图）、`zonal_stats_aligned`（对齐格网分区统计）。
