# CGDA 本地联调环境说明

面向在 Windows / Linux 上启动全栈开发环境的简要约定。完整命令见根目录 `README.md` 与 `AGENTS.md`。

## Python 运行时

- **唯一解释器**：`Env/Python312`（Windows：`Env\Python312\python.exe`）
- **勿用**系统 PATH 中的 `python` 或 `C:\Program Files\Python\...`
- 推荐入口：`start.bat` / `stop.bat`，或 `Env\Python312\python.exe launch.py <cmd>`

## Windows：Docker 必须以管理员身份运行（必读）

本仓库联调依赖 Docker Desktop 拉起 **Redis**、**MinIO**、**Open-Meteo API** 等容器。

在 **Windows** 上：

1. **Docker Desktop** 须以「**管理员身份运行**」启动。
2. 执行 `start.bat`、`launch.py start`、`launch.py sync` 等的 **终端 / Cursor 终端** 也建议以管理员身份打开。

**若不使用管理员身份，启动可能会失败**，常见表现包括：

- `launch.py start` 报「Docker 未运行或未安装」或基础设施启动失败（引擎尚未就绪时尤甚）
- 镜像无法拉取 / 无法访问
- named volume 或 Docker 引擎配置读失败
- `docker compose up` 部分服务起不全、权限相关报错

**推荐排障顺序**：

1. 退出 Docker Desktop，右键 → **以管理员身份运行** 重新启动，等待引擎就绪（托盘图标稳定）。
2. 以管理员身份打开终端，执行 `docker info` 确认无报错。
3. 再执行 `Env\Python312\python.exe launch.py start` 或 `start.bat`。

> Linux / macOS 无此 Windows 管理员要求；需保证 Docker Engine 守护进程已运行即可。

## 日常入口

| 服务 | 地址 |
|------|------|
| 前端（Vite） | http://localhost:5175 |
| FastAPI | http://127.0.0.1:8000 （文档 `/docs`） |
| Open-Meteo API | http://127.0.0.1:8080 |
| Redis | `127.0.0.1:6379` |
| MinIO | API `:9100`，Console `:9101` |

可选 Nginx 同域入口：`launch.py start gateway`（与 Vite 互斥，见 `Code/infra/gateway/README.md`）。
