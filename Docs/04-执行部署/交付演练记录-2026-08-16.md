## 四、交付机 Go 前行动项（按顺序）

1. `.env`：`BACKEND_ENV=production`（或删除 development 段）。
2. 挂载数据盘或经设置页（admin → 数据源）改 `data_root` / `BACKEND_OUTPUT_ROOT`，保存并「重启后端」。
3. 更换强 `BACKEND_API_KEY` 与 `admin` 强口令（角色/密码变更会吊销全部会话与 Token）。
4. `docker-compose.yml` 环境或 `.env`：`MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD` 改非默认，并同步后端 `BACKEND_MINIO_*`。
5. 生成并配置 `BACKEND_GEE_CREDENTIALS_ENCRYPTION_KEY`（64 hex chars / 32-byte）。
6. 配置 `BACKEND_DOWNLOAD_SOURCE_ROOT=<数据根>`（W1/G1-04 新增，production 未配则本地文件源禁用）。
7. 显式 `BACKEND_RELOAD=false`。
8. 复制 `source_uri_map.example.json` 并替换为本机构 URI。
9. `Env\Python312\python.exe launch.py restart` 后：`GET /health` 200 → `GET /layers` 确认各层 `run_readiness`。
10. （可选）`VITE_BRAND_*` / `VITE_ORG_LABEL` / `VITE_SETTINGS_TABS` 白标裁剪后 `npm run build`。
