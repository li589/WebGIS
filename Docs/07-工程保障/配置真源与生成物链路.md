## 生成物与再生成入口

### 1. 前端图层目录 `catalog-seeds.generated.json`

- **生成**：`npm run gen:catalog`（→ `Tools/generate_catalog_seeds.py`）
- **时机**：改 `catalog_seeds/*.json` 后手动跑；**prebuild 自动跑**（`npm run build` 前置）
- **CI 闸门**：`npm run check:catalog`（→ `Tools/check_catalog_drift.py`，ci.yml 已接线）

### 2. 前端色带 `weather-palettes-generated.ts`（P2-E 新增）

- **生成**：`python Tools/generate_palette_config.py`（仓库根）
- **时机**：改 `palettes.json` 后必须跑；**禁止手改生成物**
- **CI 闸门**：`Test/backend/test_catalog_consistency.py::test_frontend_generated_ts_in_sync`（幂等重跑校验）
- **注意**：生成物文件名**不含点**（`weather-palettes-generated.ts` 非 `*.generated.ts`）——TS 相对导入无法解析 basename 含点的文件

### 3. OpenAPI 类型（前端 API 类型）

- `npm run gen:types`；**加 security 依赖后必须重导 openapi + gen:types**（CI 门）
- 详见根 README / `.ai/rules/`
