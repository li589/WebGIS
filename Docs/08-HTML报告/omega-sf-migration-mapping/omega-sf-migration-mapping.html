三、EXP 实验模式：四段率定-复用链

EXP 是 Matlab 中一族递进实验设计：Exp0 是率定基线，其产物（ω_pft / ω_pixel / 逐像元 h*/α* 率定）被后续实验复用，形成"率定一次、复用多次"的链路。

Exp0 · 率定基线（默认）

CFG.EXP="Exp0"
  • 低 τ 样本 lsqnonlin 反演逐像元 h*/α*
  • 逐 8 天块反演 ω（λ=LAMBDA_SMOOTH=1 固定）
  • 产 ω_pft / ω_pixel 全局文件（L789–798）
  • 存逐像元率定 exp0_calib/*.mat（L1066–68）
  • 后续 DDCA → 逐日 SM/VOD
Python：✓ 已移植（唯一实现的模式）

Exp1a · 全复用

CFG.EXP="Exp1a"
  • h*/α* 直接读 Exp0 逐像元率定（缺文件即 error，L3167–70）
  • ω 固定（PFT/PIXEL，来自 Exp0 产物）
  • 不反演 h/α/ω，纯前向 SM/VOD
  • 用途：率定敏感性 / 快速重放
Python：✗ 未移植（无 exp0_calib 读写）

Exp1b · 半复用

CFG.EXP="Exp1b"
  • h*/α* 仍走低 τ 反演，但 ω_low 用 Exp0 固定 ω 代替反照率先验（L1033–37）
  • ω 固定来自 Exp0 产物
  • 用途：检验固定 ω 下 h/α 的稳定性
Python：✗ 未移植

Exp2 · L-curve 正则调参

CFG.EXP="Exp2"
  • λ 扫描 10⁰–10⁶（7 点），每 λ 全年块 ω 序列（L1105–92）
  • misfit–roughness L 曲线拐点自动选 λ*（pick_lcurve_corner，L3078）
  • 保存 λ–ω 序列矩阵 omega_by_lambda_block
  • 用途：平滑正则的数据驱动选择
Python：✗ 未移植（无 lambda_list / 拐点）

Python 端 retrieve_omega_sf_daily 启动横幅硬编码打印 EXP=Exp0（omega_sf.py L2701）；ω 固定加载仅实现 PFT 路径（读 omega_pft_from_exp0.mat，L2530–50）——即 Python 把"Exp0 产率定物 → 下一轮固定 ω"这一最小闭环保留了，但 Exp1a/1b/2 的实验分支没有展开。

Matlab 支持但工作流未覆盖的策略点（gap）

G1 · SF + DUAL 双温度算法未实现

Matlab 的 resid_*_dual_temp 全套存在；D2 家族（omega_avg_daily_smap_dual / gldas_online）已证明双温度实验价值。但 omega_sf.py 无 dual 残差、GLDAS 文件夹不读取。若需此工作流，先补算法移植（可复用 D2 的 GLDAS 加载与双温度组织，工作量集中在 3 个 residual/forward 函数 + 温度预读）。

G2 · Exp1a / Exp1b / Exp2率定链未移植

依赖 exp0_calib 逐像元率定缓存（Exp1a/1b）与 λ L-curve 扫描（Exp2）。Python 目前只有 Exp0 单模式。若科研上需要"率定一次、多实验复用"或正则调参敏感性，需移植对应分支；否则维持现状（每次全量率定）。

G3 · 参数点变体不建议建工作流

SF_MODE=STATIC、NDVI_MODE=DAILY_FILE、SF_INVERT/TAU_VWC2=NDVIMIN、omega_fixed_mode=PIXEL、FY_PLATFORM=3B 直读——算法已支持，属同一工作流的参数覆盖（高级参数面板可改），建独立工作流只会复制矩阵、无新链路。

G4 · ISMN 域 / SPIKE / HQFIX暂缓

ISMN 站点验证域与 SHARD 为 HPC 批处理场景，工作流已用 Celery+bbox/max_pixels 替代其定位；SPIKE 坏点删除与 YEARFILE_HQFIX 属数据质控增强，待实际数据出现坏点问题再移植更合算（YAGNI）。
