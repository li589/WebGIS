§1微波遥感反演在干什么

整套 ω 反演体系做的事情可以概括为一句话：卫星微波辐射计测到两个数（双极化亮温），我们要从这两个数里解出一组地表物理量（土壤水分、植被状况等）。这是一个典型的「反问题」——先有描述物理过程的前向模型（给定地表状态 → 预测亮温），再通过数值优化反推地表状态。

开发者的直觉类比 前向模型 = predict(state) → observation；反演 = least_squares 在参数边界内搜索使 predict(x) − observation 残差最小的 x。本系统所有反演都遵循这一模式，只是待估参数与正则项不同。

1.1 卫星测到什么（观测侧）

  • 亮温 TB（Brightness Temperature，单位 K，典型 250–320）：微波辐射计输出的辐射测量值，经普朗克函数定标换算为等效温度。
  • 双极化：电场振动方向垂直（V）/ 水平(H) 于观测平面各测一次，得 TBv、TBh。土壤水分对两种极化的响应不同——这正是反演的信息来源。
  • 入射角 θ：SMAP 恒定 40°（代码中 build_tb_model_context(freq, clay, 40.0) 的缺省即此）；FY 按像元序列 IA 逐样本传入。
图 1 · 观测几何示意：辐射计在入射角 θ 下接收经冠层调制的土壤与冠层微波发射（V/H 双极化各一个通道）

1.2 要解出什么（反演目标）

符号术语单位 / 范围物理含义（开发者视角）
SM土壤水分（体积含水量）m³/m³，约 0.02–0.5最终产品之一。水分越高 → 土壤介电常数越大 → 反射越强、发射越弱
τ（VOD）植被光学厚度无量纲，≥ 0植被「厚度」指标，对微波的消光总量；透过率 γ = e−τ。最终产品之一（DDCA 同时反演 SM 与 τ）
ω单次散射反照率0–1冠层消光中被散射（而非吸收/发射）的比例。本算法族的核心待估参数，不可直接观测，须由时序联合优化估计
h表面粗糙度参数≥ 0土壤表面粗糙度对镜面反射的衰减与增强调制
α极化混合系数缺省 0.1771（ALPHA0）粗糙度引起的 V/H 极化能量交换比例，Q = max(α·h, 0)
Ts / TC / TG物理温度：单温度 / 冠层 / 有效土壤K发射体的热力学温度乘子。单温度方案三者合一为 Ts；双温度方案拆分为 TC（冠层）与 TG（土壤）
为什么 ω 需要一整个算法族 亮温对 SM、τ、ω、h、α 是多参数耦合的，单像元单时刻两个观测方程解不出这么多未知数。策略是：用时间维度换自由度——假设 h/α 在一个时间块内近似不变、τ 可由 NDVI 独立估计、ω 在时间上缓变（加平滑正则），于是块内多日观测可以联合解出这组参数。三族算法（§3）就是三种不同的「时间组织 + ω 策略」。

§2τ-ω 前向模型：单温度 vs 双温度

τ-ω 模型是微波遥感植被覆盖地表的零阶辐射传输模型（zero-order RT）：不做多次散射求解，只把到达传感器的辐射拆为「透过冠层的土壤发射」与「冠层自身发射/散射」两项叠加。全部前向计算按以下链条进行：

层级环节输入 → 输出（实现位置）
①介电模型ε(SM, clay, freq) —— Mironov (2015) 模型，physics.mironov_dielectric_from_context
②菲涅耳反射rh, rv(ε, θ) —— 平滑地表反射率，build_fresnel_context + fresnel_reflectance_from_context
③粗糙度校正rh,r, rv,r(r, h, α, θ) —— 见式 (2)，Q = max(α·h, 0)
④τ-ω 叠加TBv, TBh(SM, τ, ω, h, α, T, θ) —— 见式 (1)/(3)，分单温度 / 双温度两版
式 (1) · 单温度前向（ORIG_TS）
TBv = Ts · [ (1−rv,r)·γ + (1−ω)(1−γ)(1+rv,r·γ) ]
TBh = Ts · [ (1−rh,r)·γ + (1−ω)(1−γ)(1+rh,r·γ) ] γ = e−τ；土壤发射项与冠层项共用同一温度乘子 Ts
式 (2) · 粗糙度校正（两方案共用）
Q = max(α·h, 0)， rh,r = [(1−Q)·rh + Q·rv] · e−h·cos²θ， rv,r = [(1−Q)·rv + Q·rh] · e−h·cos²θ α 退化为固定 0.1771 时对应原始 F_sm.m
式 (3) · 双温度前向（DUAL）
TBv = TG·(1−rv,r)·γ + TC·(1−ω)(1−γ)(1+rv,r·γ)
TBh = TG·(1−rh,r)·γ + TC·(1−ω)(1−γ)(1+rh,r·γ) C=1.0；土壤发射项乘 TG，冠层发射/散射项乘 TC

对应实现：_forward_tb（omega_sf.py L1185，Matlab tb_forward_single_temp L2166–2176）与 _forward_tb_dual（L1514，Matlab tb_forward_dual_temp L2245–2255）。两版除发射项温度乘子外完全共用 Mironov 介电、Fresnel 与粗糙度层。

2.1 单温度 vs 双温度：差别到底在哪

■ 单温度（temp_scheme = ORIG_TS）

假设：土壤表层与冠层热平衡，共用一个物理温度 Ts（直接取卫星数据自带的 surface_temperature，别名 Ts）。

优点：不依赖外部温度数据，SMAP/FY 数据包内即含 Ts。

偏差来源：白天太阳加热下，土壤表层与冠层温差可达数 K；用单一 Ts 乘两项会把该温差误差直接注入 SM/τ 反演结果。

■ 双温度（temp_scheme = DUAL）

假设：冠层温度 TC 与有效土壤温度 TG 分离，分别乘冠层项与土壤项（式 3）。

数据需求：须外接 GLDAS 陆面再分析，提供三温度层——地表温度 Ts_gldas（作 TC）、两层土壤温度 Tsoil1/Tsoil2（合成 TG，见式 4）。

代价：多一路 GLDAS 预读、过境时刻匹配与日期交集过滤（见 2.3）。

图 2 · 两种温度方案的辐射分解：左图为单温度共用 Ts；右图 DUAL 将土壤发射项（琥珀色）与冠层项（绿色）分别配温

2.2 TG 的三种合成模式（dual_tg_mode）

GLDAS 提供两层土壤温度，而前向模型只要一个有效土壤温度 TG，因此需要一个合成方案。实现位于 ingest/daily_bundle.py 的 build_effective_soil_temperature_scheme（L863–891）：

式 (4) · PAPER_CT 模式（论文方案，缺省）
Ct = ( SMref / SMref* ) p， TG = Tsoil2 + Ct · ( Tsoil1 − Tsoil2 ) SMref* = ct_smref = 0.30，p = ct_exp = 0.30
dual_tg_modeTG 取值语义
PAPER_CT（缺省）Tsoil2 + Ct(Tsoil1−Tsoil2)有效深度随土壤水分变化的幂律插值：越湿润（SM_ref 越大）→ Ct 越大 → TG 越靠近表层 Tsoil1；越干燥则越靠近深层 Tsoil2。物理上模拟微波采样深度对湿度的依赖
TSOIL1_ONLYTsoil1直接取表层土壤温度（消融实验/对照基线）
TSOIL2_ONLYTsoil2直接取深层土壤温度（同上）

2.3 GLDAS：为什么需要、怎么接

为什么必需：双温度方案的 TC/TG 无法从 SMAP/FY 数据包获得——SMAP 自带的 Ts 恰是单温度方案要替换掉的那个量。GLDAS（Global Land Data Assimilation System，NASA 陆面再分析）以 3 小时间隔提供全球陆面状态，本系统使用其中的三温度层（Ts_gldas、Tsoil1、Tsoil2）。

时间匹配（过境匹配法）：卫星降轨过境发生在某本地时 h（SMAP 06:00，FY3D/FY3B 各有独立配置项），而 GLDAS 文件打 UTC 时戳。给定研究区经度范围 [lon_min, lon_max]，某日 day 的目标 UTC 匹配窗口为：

式 (5) · GLDAS 过境匹配 UTC 窗口
[ day + h − lonmax/15 − tol ,　day + h − lonmin/15 + tol ] tol = gldas_time_tol_hours = 1.6 h（缺省）；经度/15 即地方时与 UTC 的时差
  • 窗口内存在 GLDAS 文件 → 该日保留，取最近邻文件读取三温度行（load_dual_temperature_row_for_day；线性像元索引按 loader 约定 0-based → 1-based 传递）。
  • 整月无任何可匹配日 → 按 Matlab 原型的「日期交集」语义，该月从运行序列剔除（_filter_tvec_by_gldas_days，在 8 天块构建之前执行，保证块结构一致性）。
  • 像元级无匹配（个别像元 NaN）→ 由反演内部的 NaN 短路掩膜自然跳过，不中断整块。
  • 模板法（use_gldas_template=True）：无法用经度窗口预判（模板不按日期命名）时保留全部日期，逐日直接按模板读取。

「平均 avg / 动态 raw」的准确语义 用户语言中的「平均」指 ω 取气候态平均值（D2：ω 在同 DOY 的多年样本上平均后固定），「动态」指 ω 保留并逐块反演真实时序（SF）。两者反演的 SM/VOD 都是逐日产品——差别只在 ω（以及连带的质量控制路径），不在时间分辨率。

4.1 各步细节

步骤待估参数残差构造与求解器关键控制参数
Step 0τ*(t)（非优化，经验式）由 NDVI 时序、NDVI 气候态极值（ndvi_max/min）、IGBP 土地覆盖类型、B 参数、SF 与入射角序列计算（tau_from_ndvi，矢量化）b_param、IGBP 分支参数

4.2 单/双温度的三个分支点

流水线结构对两种温度方案完全同构——唯一差异是前向算子与温度输入。切换由参数 temp_scheme（ORIG_TS / DUAL）控制，三处接线：

接线点ORIG_TS（单温度）DUAL（双温度）
Step 1（~L699）_resid_halpha_single_temp（ts 序列）_resid_halpha_dual_temp（tc/tg 序列）
Step 2（~L1082）_resid_omega_block_single_temp_resid_omega_block_dual_temp
Step 3（~L838）_ddca_single_temp 路径_ddca_dual_temp（残差 _f_sm_dual_temp）

DUAL 的有效性掩膜同步扩展：ok_base 将 Ts 有限性检查替换为 TC 与 TG 双序列有限性（TG 依赖 SM_ref 与 Tsoil1/Tsoil2，见式 4）；TG 在像元核心内即时合成（build_effective_soil_temperature_scheme）。DUAL 运行前，日期向量已按 GLDAS 可匹配性过滤（§2.3），_preload_chunk 返回 10 键（ORIG_TS 为 7 键），多余三键即 TC/Tsoil1/Tsoil2。
