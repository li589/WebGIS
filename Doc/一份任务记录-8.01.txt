omega_sf_fenkuai 反演算法详细分析
文件说明
D1_raw_omeg.m 与 omega_sf_fenkuai.m 是完全相同的文件（~3515 行，116KB），均定义主函数 OMEGA_IDENT_FAST()。Function/ 文件夹（注意首字母大写）包含 13 个物理/工具函数。两个主文件通过 grep 验证，所有子函数定义在相同行号处完全一致。

一、Exp0 算法流程
1.1 整体架构（主函数 OMEGA_IDENT_FAST，行 9-801）
算法采用三步反演结构，核心是 τ-ω 模型（tau-omega model）的微波辐射反演：


Plain Text

配置 → 时间交集 → 静态库加载 → 任务构建 → 分片 → 预映射 → 分块预读 → 逐像元反演 → 汇总输出 → Exp0后处理
1.2 数据输入
输入类别	文件来源	关键变量
亮温 TB	FY3D/FY3B .mat 或 SMAP .mat	TBv, TBh, IA(入射角)
土壤水分参考	SMAP sm_dca / DDCA SM / ISMN grid	SMref_mat
NDVI	每日文件 或 DOY 气候态	NDVI_mat

VWC	SMAP 日文件 vwc	vwc_row（用于 SF 倒推）

NDVI 气候态	NDVI_clim/ 按 DOY 1~366 命名	NDVI_clim_max, NDVI_clim_min
时间交集（行 261-329）：对 tvec_req(请求日期)、T_tb(亮温日期)、T_smap、T_ndvi、T_smref 取交集，DUAL 温度方案时再并入 T_gldas_day。

1.3 处理步骤
Step 0 — Tau 计算（行 970-977，函数 Tau 行 2497-2550）：

由 NDVI 计算植被含水量 VWC，再算光学厚度 τ

VWC1（叶片项）= 1.9134*NDVI² - 0.3215*NDVI

VWC2（灌木/枝干项）按地类分两种模式（TAU_VWC2_MODE）：

POINT1：草地/农田用 (NDVI-0.1)/0.9，其他用 (NDVI_max-0.1)/0.9
NDVIMIN：用 (NDVI-NDVI_min)/(1-NDVI_min) 归一化
τ = b * VWC * sec(θ)，θ 为入射角

Step 1 — h/alpha 反演（行 1006-1071）：

筛选低 τ 样本（tau_thr = tau_min + 0.05*(tau_max-tau_min)）

用 lsqnonlin 最小化残差 resid_halpha_single_temp（行 2116-2127）

残差 = [√wV*(TBv_m-TBv); √wH*(TBh_m-TBh); √λ_alpha*(alpha-alpha0)]

边界：h∈[0,3]，alpha∈[0.05,0.35]

Exp0 保存逐像元率定结果到 exp0_calib_pix_{iy}_{ix}.mat

Step 2 — 逐 block 反演 omega（行 1080-1310）：

对每个 8 天 block，用 lsqnonlin 反演单个 ω 值

残差 resid_omega_block_single_temp（行 2129-2143）= [√wV*(TBv_m-TBv); √wH*(TBh_m-TBh); √λ_smooth*(ω-ω_prev)]

时间平滑项：若前一 block 的 ω 有效且间隔不超过 block_days+2 天，加入正则化

边界：ω∈[0,1]

DDCA 回带（行 1326-1351）：

用反演得到的 ω、h*、alpha* 回带 DDCA 反演逐日 SM 和 VOD

porosity = 1 - BD/2.65

3.4 潜在精度隐患
Fresnel 中 sqrt(eps - sind(Theta)²)：当入射角较大且土壤介电常数较小时，eps - sin²θ 可能为负，产生复数。代码用 abs()² 取模，物理上等价于全反射，但 Python 复现时需注意使用 np.abs() 而非直接平方。

Mironov 模型中 SM-zxmvt（行 39）：当 SM < zxmvt（最大结合水含量）时，zflag=0，自由水项为 0；Python 中需用 np.where 或 mask 实现而非直接乘法。

secd(theta) = 1/cos(θ)（Tau 行 2547）：若 θ 接近 90° 会溢出，但实际 SMAP/FY 入射角约 40°，安全。

exp(-Tau) vs exp(-Tau*sec(θ))：代码注释说明"在计算 Tau 时进行过角度矫正"（F_sm.m 行 17），即 τ 已乘 sec(θ)，故 gamma 直接用 exp(-Tau) 而非 exp(-Tau*sec(θ))。Python 复现时需保持一致。

四、8 天 Block 结构
4.1 Block 定义（make_viirs8_blocks，行 2813-2831）

matlab

blkStartsAll = datetime(yy,1,1) + days(8*floor((doy-1)/8));
按年划分：每年从 1 月 1 日开始，DOY 1-8 为第 1 块，9-16 为第 2 块，依此类推

block_start = 该年 1 月 1 日 + 8*floor((doy-1)/8) 天

block_end = 该 block 内 tvec 中的最后一个实际日期（不超过该年最后一天）

block_index = {1×Kb cell}，每个 cell 存该 block 内的日期索引数组

最后一个 block 可能不足 8 天（如 365 天年：45 个完整 8 天块 + 1 个 5 天块）

4.2 数据聚合方式
每个 block 反演一个 ω 值：将该 block 内所有 valid_tau 日的 TB/Ts/Tau/SM/IA 打包为残差向量，用 lsqnonlin 反演标量 ω

时间平滑正则化（行 1198-1203, 2138-2142）：若前一 block 的 ω 有效且时间间隔 ≤ block_days+2（即 10 天），加入 √λ_smooth*(ω-ω_prev) 项；否则不加入

block 间断检测：gapDays = days(blkStarts(bb)-prev_blkStart)，若 > 10 天则 omega_prev = NaN

输出回填（行 1243）：OMEGA(ib_use) = om_hat，block 内所有有效日赋同一 ω 值

block 网格输出（行 1883-1984）：每个 block 生成一张 OMEGA_grid(nrow,ncol)，像元值取该像元在该 block 内 OMEGA 的中位数

八、SF 倒推公式（build_sf_row_daily，行 3378-3440）

Plain Text

vwc_leaf = 1.9134*NDVI_clim² - 0.3215*NDVI_clim   (叶片项，用气候态 NDVI)
vwc_wood = vwc_row - vwc_leaf                       (灌木/枝干项，由 SMAP VWC 减叶片)
sf = vwc_wood / den                                 (归一化)
den 按模式和地类：

POINT1：草地/农田用 (NDVI_clim-0.1)/0.9，其他用 (NDVI_clim_max-0.1)/0.9

NDVIMIN：用 (NDVI_clim-NDVI_clim_min)/(1-NDVI_clim_min)

QC：den<=0 或 sf<0 或水体（cls==0）时置 NaN。
